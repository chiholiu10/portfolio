# Tools content

Tool categories are managed in Contentful, in the `arrays` field of the Tools section (`2FzwztBT4JTZm5icaV1tlb`, environment `master`). Tool names and published SVG assets are managed through the section's `arrayBlock` field. The frontend does not add fallback tools or local icon paths.

Tools are grouped into **Core frontend**, **Frontend quality**, **Delivery and platforms**, **APIs and backend**, and **Applied AI and validation**. Changes become visible after the site's Contentful data is refreshed through regeneration or a new build.
