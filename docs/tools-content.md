# Tools content

Tool categories are managed in Contentful, in the `arrays` field of the Tools section (`2FzwztBT4JTZm5icaV1tlb`, environment `master`). The frontend uses these categories directly; `apps/web/lib/tools.ts` supplies additional tool names and icons.

On 2026-10-12, Codex was moved from **Core expertise** to **Familiar with** and the Tools section was published. The Codex icon remains available. Changes become visible after the site's Contentful data is refreshed through regeneration or a new build.
